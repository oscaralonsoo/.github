# Nobody Games

We are a group of third-year students from <a href="https://www.citm.upc.edu/">CITM (Centre de la Imatge i la Tecnologia Multimèdia)</a>. For our project, we are developing a video game set in our own original universe called Son Of Ithaca, inspired by the Odyssey. The project is powered by <a href=https://github.com/NobodyGamesStudio/WaveEngine>Wave Engine</a>, a custom game engine created and developed by our team.
